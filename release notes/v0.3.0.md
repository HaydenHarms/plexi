# Plexi 0.3.0

_Released November 5, 2026_

## New

- **macOS.** A universal Plexi.app for Apple silicon and Intel, shipped as a dmg and a zip. Draw-on-screen covers the main display. Screenshots need Screen Recording permission.
- **Automatic updates.** A few seconds after launch, Plexi quietly checks GitHub for a newer release. If one exists, a corner notice offers Update now, Later, Skip this version, or What's new. You can also run "Check for updates" from Settings or Ctrl+K.
  - Installed copies download the new installer, run it silently and restart.
  - Portable copies replace their own exe.
  - MSI installs and macOS open the release page instead.
  - Downloads are checked against the release's SHA256SUMS.txt, and your notes are saved before anything is replaced.
