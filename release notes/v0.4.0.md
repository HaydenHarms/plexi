# Plexi 0.4.0

_Released November 6, 2026_

## New

- **Snip.** Drag over any area of the screen with the scissors button, Ctrl+Alt+S from anywhere, the tray, the command palette or the snapshot menu. The snip goes to the clipboard, and also onto the page if you started it from the notebook.
- **Crop images.** Right-click an image, choose Crop image, drag the edges and press Enter. Crops are non-destructive ("Remove crop") and appear in every export.
- **Text styles.** A bar under the toolbar sets the font (any installed family), size, bold, italic and underline. It applies to the box you're editing, the selected boxes, or new ones. Exports use the same fonts, so they match the screen.
- **Print or export only some sheets**, such as `1, 3, 5-7`. Ctrl+P opens the PDF in your system viewer to print. The CLI gains `--sheets`.
- Sheet outlines and sheet numbers can be shown or hidden separately.

## Changed

- Double-click a text box to edit it. Clicking the toolbar no longer ends the edit.
