# Plexi 0.8.3

_Released November 11, 2026_

## Fixes

- **Only one Plexi runs at a time.** If Plexi was already running, say because it started with Windows, opening it again started a second copy, and the first copy kept the hotkeys. Now opening Plexi brings up the copy that's already running instead: the notebook comes to the front, a `.plexi` file you double-click opens in it, and the hotkeys and tray icon keep working.
