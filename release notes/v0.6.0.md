# Plexi 0.6.0

_Released November 9, 2026_

## New

- **Snapshot tool.** Drag a box over part of the page and it goes to the clipboard as a picture. It's in the new select tools menu.
- **Undo in the handwriting window.** Ctrl+Z takes back the last stroke, clear or clear-all, and Ctrl+Y brings it back. The page's own undo is left alone while the window is open.

## Changed

- **Select tools share one toolbar button.** Lasso, rectangle select and snapshot are in its menu, and the button shows the one you used last.
- **Copy and paste stay inside Plexi.** Ctrl+C no longer puts a picture on the system clipboard. Use the snapshot tool for that.
- **Text box handles** now sit in the middle of the left and right sides of the dashed outline, instead of inside its corners. The hand and text tools can drag them too, including while you're typing in the box.
- **The hand tool** has a new icon, and its cursor is now a hand that closes while you drag. Before, Windows showed four-way move arrows. Clicking empty canvas with the hand now deselects.
- **Seamless pages.** With sheet outlines and sheet numbers both off, a fixed-size page has no drop shadow, so it blends into the canvas.

## Fixes

- The handwriting window lays its boxes out in rows and opens centered. Before, it could grow into one long row that pushed the boxes and the Save font button off screen.
- Text in your own handwriting came out as thick blobs: every line in the generated font was at least a third of a letter wide. Lines are now as thin as you wrote them. Fonts you already saved fix themselves the next time Plexi builds them.
