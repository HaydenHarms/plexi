# Plexi 0.5.0

_Released November 8, 2026_

## New

- **Type in your own handwriting.** Write a sample of each character with the pen in the handwriting window. Open it from the font picker, the File menu or Ctrl+K. Plexi turns your samples into a real font that takes effect right away, in the editor and in every export.
- **Animated GIFs play on the canvas**, crop included. Exports show the first frame.
- **Rectangle select (M)**, alongside the freeform lasso, with the same selection, resizing and Shift-extend behavior.
- **Hand tool (G).** Drag empty canvas to pan, or drag an element to move it. It never draws.
- **Copy and paste selections** with Ctrl+C and Ctrl+V. Pasted copies land in the middle of the view. A copy also goes to the system clipboard as a picture.
- **Shift-click multi-select.** Shift+click adds an image, text box or stroke to the selection, or removes it if it's already selected. Shift+lasso adds to the selection instead of replacing it.
- **Text box wrap width.** Drag a corner handle of a selected text box to set where its text wraps. Exports wrap the same way.

## Changed

- Dragging an image's corner now resizes it freely. Hold Shift to keep its proportions; this used to be the other way around.
